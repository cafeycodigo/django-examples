# Aplicación Fútbol Chileno & Campeonatos (`futbol`)

Para consultar la documentación completa de la aplicación, visita el archivo principal:

👉 **[README_FUTBOL.md](../README_FUTBOL.md)**

### Resumen rápido

- **Modelos:** `Club`, `Jugador`, `Campeonato`, `Partido`, `Incidencia`.
- **Clubes de Chile:** 32 clubes reales (16 Primera División, 16 Primera B).
- **Seeder:** `python manage.py seed_futbol --reset`
- **Ruta Principal:** `/futbol/`
- **Reporte de Lesionados:** `/futbol/lesionados/`
- **Tarjetas y Sancionados:** `/futbol/sancionados/`
- **Partidos con Goleadas:** `/futbol/goleadas/`
- **Tabla de Posiciones:** `/futbol/tabla-posiciones/`
- **Tabla de Goleadores:** `/futbol/goleadores/`
- **Tests:** `python manage.py test futbol`
