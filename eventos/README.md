# Aplicación Eventos (`eventos`)

Para consultar la documentación completa de la aplicación, consulta el archivo principal:

👉 **[README_EVENTOS.md](../README_EVENTOS.md)**

### Resumen rápido

- **Modelos:** `Categoria`, `Evento`, `Persona`, `Asistencia`.
- **Comando Seeder:** `python manage.py seed_eventos --reset` (Genera >500 eventos y 30.000 personas asistentes en ~5 segundos).
- **Ruta Web Principal:** `/eventos/`
- **Panel Admin:** `/admin/eventos/` (usuario: `admin`, clave: `admin`)
- **Tests:** `python manage.py test eventos`
